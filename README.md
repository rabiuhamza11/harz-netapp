# HARZ Network App Kit (v0.2, Oct 2, 2026)

The .harz address bar for your phone. Self-contained kit: sealed zone v2 + door + address bar page.

## Run (Termux)
1. pkg install git nodejs -y  (one time)
2. git clone https://github.com/rabiuhamza11/harz-netapp.git
3. cd harz-netapp
4. bash phone-start.sh

The door boots on 127.0.0.1:8080 and the address bar opens in your browser.
Type kasuwa.harz and press Open — the sealed zone answers, the receipt shows, the endpoint opens.
Unknown names get honest NXDOMAIN with a receipt.
